# The Virtue Initiative

[The Virtue Initiative](https://virtueinitiative.org) is a nonprofit project aimed at creating a free screenshot based accountability app.

Learn more about us by visiting our [homepage](https://virtueinitiative.org).

The code for the apps, website, and API is at [virtue-initiative](https://github.com/virtue-initiative/virtue-initiative), which contains the code for the desktop apps, web app, and API.
